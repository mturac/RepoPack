# RepoPack v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, secret-safe, budget-bound repository context compiler for coding agents.

**Architecture:** A read-only discovery layer normalizes repository files and Git state. Deterministic scoring, secret filtering, dependency extraction, and budget allocation produce a canonical bundle consumed by CLI, Markdown rendering, comparison, and public APIs.

**Tech Stack:** TypeScript 5.8, Node.js 22+, ESM, Node test runner, zero runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-08-28-repopack-design.md`

## Global Constraints

- Node.js 22 or newer.
- Zero runtime dependencies and zero network calls.
- No raw secret matches or absolute host paths in artifacts.
- Every selection score and omission must carry machine-readable evidence.
- Output must be deterministic for identical repository state, task, and configuration.
